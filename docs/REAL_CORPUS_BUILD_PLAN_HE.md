# תוכנית הרחבה לקורפוס עברית מודרנית

## יעד v1

| slice | יעד מינימום |
|---|---:|
| מסמכים ציבוריים/מנהליים | 200 עמודים |
| חקיקה ומשפט | 100 עמודים |
| דוחות עם טבלאות/תרשימים | 75 עמודים |
| טפסים ומבנים קשיחים | 50 עמודים |
| mixed BiDi צפוף | 100 עמודים |
| סריקות קשות/צילום | 100 גרסאות מקור |

עמוד יכול להשתייך לכמה slices. היעד הכולל הראשוני הוא לפחות 500 עמודים מ־100 מסמכים ו־50 משפחות תבנית.

## איכות אמת־המידה

- אנוטציה כפולה במדגם משמעותי;
- adjudication למחלוקות;
- IAA ברמת תו, שורה, אזור וטבלה;
- חיפוש exact/near duplicates;
- review חזותי של כל test page;
- hidden test עם מזהים opaque.

## הרחבות עתידיות

כתב יד מודרני, קבלות/חשבוניות ומסמכים מהעולם הפרטי ייכנסו רק עם מקור חוקי, transcription אנושי ו־PII review. הם לא יעכבו או יזהמו את ציון הדפוס הראשי.
