# תוכנית הרחבה לקורפוס עברית מודרנית

## יעד v1

| slice | יעד מינימום |
|---|---:|
| מסמכים ציבוריים/מנהליים | 200 עמודים |
| חקיקה ומשפט | 100 עמודים |
| דוחות עם טבלאות/תרשימים | 75 עמודים |
| טפסים עם gold אמיתי ברמת שדה | 50 עמודים |
| mixed BiDi צפוף | 100 עמודים |
| סריקות קשות/צילום | 100 גרסאות מקור |

עמוד יכול להשתייך לכמה slices. היעד הכולל הראשוני היה לפחות 500 עמודים
מ־100 מסמכים ו־50 משפחות תבנית. ה־roots המודרניים הנוכחיים מוסמכים,
אבל יעד הטפסים לא הושלם: אותות discovery אינם אנוטציית שדות וב־700 עמודי
המקור נמצאו אפס `form_fields`.

## איכות אמת־המידה

- אנוטציה כפולה במדגם משמעותי;
- adjudication למחלוקות;
- IAA ברמת תו, שורה, אזור וטבלה;
- חיפוש exact/near duplicates;
- review חזותי של כל test page;
- חבילת evaluation עם מזהים opaque ו־gold נפרד מחבילת המשתתף, בלי טענת
  unseen למקורות public-fixed.

## הרחבות עתידיות

כתב יד מודרני ו־Pinkas כבר קיימים כהרחבות אמיתיות נפרדות. דפוס HaZefira
קיים כהרחבה היסטורית צרה ומעורבת, לא pure-Rashi. קבלות/חשבוניות ומסמכים
מהעולם הפרטי ייכנסו רק עם provenance, transcription אנושי ו־PII review.
אף הרחבה אינה משנה את ציון הדפוס הראשי.
