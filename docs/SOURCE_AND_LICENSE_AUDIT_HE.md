# ביקורת מקור, זכויות ו־provenance

לכל מסמך בקורפוס המודרני נשמרים:

- source ID ו־publisher;
- דף מקור ו־URL לקובץ;
- publication/update date;
- SHA-256 של קובץ המקור;
- מספר עמודים צפוי;
- רישום זכויות/ייחוס;
- מזהה תבנית ו־split group;
- החלטת הכללה או דחייה וסיבתה.

ה־audit מוודא שה־URL וה־hash נעולים, שהקובץ תקין, שהמסמך שייך לעברית מודרנית ושאין שימוש בשכבת טקסט בלתי מהימנה. מקור שאין לו evidence מספיק נשאר candidate ואינו נספר בציון הרשמי.
