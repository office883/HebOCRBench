# ביקורת מקור, זכויות ו־provenance

לכל מסמך בקורפוס המודרני נשמרים:

- source ID ו־publisher;
- דף מקור ו־URL לקובץ;
- publication/update date;
- SHA-256 של קובץ המקור;
- מספר עמודים צפוי;
- רישום זכויות/ייחוס;
- מזהה תבנית ו־split group;
- החלטת הכללה או דחייה וסיבתה.

ה־audit מוודא שה־URL וה־hash נעולים, שהקובץ תקין, שהמסמך שייך לעברית מודרנית ושאין שימוש בשכבת טקסט בלתי מהימנה. מקור שאין לו evidence מספיק נשאר candidate ואינו נספר בציון הרשמי.

בהרחבות נשמר אותו עיקרון זהות, אך כל משפחה נבדקת לפי ה־gold שלה:

- Pinkas נעול ל־266 שורות עבריות משישה עמודים ומסנן fail-closed חומר
  שומרוני מה־TAR המעורב;
- HaZefira נעול ל־34 תמונות, PAGE ו־ALTO ול־4,016 מזהי שורה תואמים;
- diagnostics סינתטיים נעולים ל־shards ולמסננים של 500 שורות כל אחד ומסומנים
  non-rankable;
- כל מקור public-fixed מתועד ככזה, בלי טענת unseen או contamination-free.
